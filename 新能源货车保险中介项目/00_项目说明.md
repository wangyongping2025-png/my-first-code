# 新能源货车保险中介项目 · 项目说明

## 一句话定位
为投保困难的新能源大货车(车队/车主)对接愿意承保的保险公司,从中赚取业务手续费的**保险中介撮合**业务。

## 我是谁 / 我的角色
- 中间撮合方(中介/渠道):一手对接需要投保的车队,一手对接能"开口子"承保的保险公司。
- **核心资产:保险公司端的关系与人脉**(能拿到承保口子)。

## 业务范围(当前)
- 主做:新能源大货车 **车险(车损)** + **三者险**;附带 **司机意外险**。
- 暂不做:货运险 / 零担货运责任险。

## 盈利模式
- 赚取保险公司给的 **手续费 / 返佣**(收车队业务 → 走保险公司承保 → 拿返佣)。

## 我目前的短板(要补的)
- 不熟:国家政策、监管规定、行业情况。
- 不清楚:市场行情、客户真实需求。
- 不掌握:保险公司的承保逻辑(何时开/关口子)、手续费水平、结算方式。

## 项目目标
- **短期**:摸清行情 + 跑通第一单,验证模式跑得通。
- **中期**:建立稳定的"客户端获客 + 保险公司端渠道"双边关系,形成可持续的撮合业务。
