# 新能源货车保险中介 · 问题框架(研究地图)

把整个项目拆成 5 大块。每块列出"必须搞清楚的关键问题",我们一块一块往下填。
（建议研究重心:**模块三 > 模块二 > 模块一**,因为你的命脉在保险公司端。）

## 模块一:行业与政策(打底,搞懂大环境)
- 新能源大货车(营运货车)全国保有量、增速、主要分布区域?
- 为什么保险公司普遍不愿承保?(出险率、赔付率、维修/电池成本、营运车风险……到底哪几条是关键)
- 国家对新能源货车有哪些扶持 / 上路 / 营运政策?
- 车险综合改革后,商业车险、三者、交强险的费率与承保规则是怎样的?
- 监管对"营运货车""新能源车"承保有没有特殊要求或窗口?

## 模块二:客户端(车队/车主 —— 需求方)
- 典型客户长什么样?(个人车主 / 小车队 / 大车队,各自比例与特点)
- 他们最大的痛点?(被拒保 / 保费太高 / 续保难 / 理赔难)
- 投保时最看重什么?拍板的人是谁?
- 我从哪里找到他们?(获客渠道:车管所、4S、挂靠公司、物流园、行业群、老带新……)

## 模块三:供给端(保险公司 —— 承保方,**最关键**)
- 目前哪些保险公司 / 分支机构在承保这类车?哪些在收紧?
- "开口子 / 关口子"的规律是什么?(受赔付率、季度/年度KPI、区域配额影响?一般什么时间点松/紧?)
- 给中介的手续费 / 返佣大概什么水平?怎么谈?
- 结算方式与周期?(回款怎么走、有没有垫资风险)
- 怎么建立和维护这层关系,让口子稳定?

## 模块四:我的中介模式与变现(把链条跑顺)
- 我在链条里到底提供什么价值?(撮合 / 议价 / 服务 / 兜底?)
- 收费方式:纯返佣 / 差价 / 服务费?一单大概能赚多少?
- 资金与单据怎么走?(保费谁收、发票、合同)
- ⚠️ **合规红线**:保险中介在国内需要资质 / 牌照。无证收佣金有法律风险——是否需要"**挂靠持牌中介机构**"来合规经营?(这条必须先搞清,免得踩雷)

## 模块五:执行与落地(先跑起来)
- 现有资源盘点:我手上的保险公司关系、客户线索分别有哪些?
- MVP:怎么用最小成本跑通"第一单"?
- 风险清单:政策风险、口子突然关、回款、合规……各怎么应对?
