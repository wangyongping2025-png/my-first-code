# YouTube 文案提取小工具 · 使用说明

这个工具帮你把 YouTube 视频里的文字**抓出来**（生成文字稿）。
整理/排版交给你自己的 Claude / GPT，工具不碰云、不上传你的内容。

---

## 一、视频分两种，处理方式不同

在 YouTube 播放器点**齿轮 ⚙ 设置**，看有没有「字幕」这一项：

- **有「字幕」选项 = 软字幕** → 用本工具的蓝色按钮，免费、秒出。
- **没有「字幕」选项 = 硬字幕**（字印在画面里） → 抓不出来，用下面「没字幕怎么办」。

---

## 二、日常使用（四步）

1. **先开着翻墙**（鸟云加速，连上）。
2. 打开「终端」，进入 wenan 文件夹（打 `cd ` 加空格，再把 wenan 文件夹拖进终端，回车）。
3. 启动：
   ```
   python3 app.py
   ```
   看到 `http://127.0.0.1:5050` 就成功了，**别关这个终端窗口**。
4. 浏览器打开 **http://127.0.0.1:5050**，粘 YouTube 链接，点按钮。

用完：回终端按 `Control + C` 关掉。

---

## 三、网页上两个按钮

- **蓝色「提取文案（有字幕用这个）」**：抓字幕，出文字稿。
  - 出结果后可：复制（整理指令＋文字稿）／只复制文字稿／下载 txt。
  - txt 也会自动存到 `wenan/outputs` 文件夹。
- **绿色「下载音频（没字幕用这个）」**：把音频下载下来，存到 `outputs` 文件夹。
  - 然后把音频文件**拖进本地 Whisper 软件**转成文字。
  - 注意：YouTube 对下载卡得严，**部分视频可能下不了**，属正常现象。

---

## 四、没字幕怎么办

1. **首选（免费）**：点绿色「下载音频」→ 成功的话拖进本地 Whisper 软件转文字。
2. **下不了时（省事但花钱）**：用 WhisperTranscribe.ai 的「从 URL 转录」，粘链接出全文（按量/订阅收费）。
3. 出来的文字，拿去你自己的 Claude / GPT 整理排版。

---

## 五、常见问题

- **打开 5050 显示"连接被拒绝"**：程序没在跑。回终端 `python3 app.py` 启动，别关窗口。
- **提示「证明你不是机器人」**：在 Chrome 里登录 YouTube，再点一次。
- **提示「网络不稳定 / SSL」**：换个翻墙节点再试；工具已固定走代理 `127.0.0.1:6376`。
- **代理端口变了**：在 wenan 文件夹建一个 `proxy.txt`，里面写新的 `127.0.0.1:端口`。
- **提示「没找到字幕」**：这个视频是硬字幕，没有可提取的文字，走「没字幕怎么办」。
- 任何看不懂的红字，截图问就行。
