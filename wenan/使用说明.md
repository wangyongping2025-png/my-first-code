# YouTube 文案提取小工具 · 使用说明（第一步：抓字幕）

这一步全部免费，不需要注册任何账号。

## 一、第一次使用：装好需要的东西（只做一次）

1. 打开 Mac 的「终端」（在「启动台」里搜 `终端` 或 `Terminal`）。
2. 把下面这行**整段复制**进终端，按回车，进入工具文件夹：

   ```
   cd ~/my-first-code/wenan
   ```

   > 如果你的项目不在这个位置，把它换成你电脑上 `wenan` 文件夹的实际路径。
   > 偷懒办法：在终端里先打 `cd ` （cd 后面有个空格），再把 `wenan` 文件夹直接拖进终端窗口，回车即可。

3. 安装需要的两个工具（Flask 网页、yt-dlp 抓字幕）：

   ```
   pip3 install -r requirements.txt
   ```

   看到一堆文字、最后没有红色 `error` 就算成功。
   - 如果提示 `pip3: command not found`，把上面命令里的 `pip3` 换成 `python3 -m pip`。

## 二、每次使用：启动工具

1. 终端里进入文件夹（同上第 2 步的 `cd ...`）。
2. 输入这行并回车：

   ```
   python3 app.py
   ```

3. 看到提示 `请在浏览器打开： http://127.0.0.1:5000` 就成功了。
4. 打开浏览器（Safari/Chrome 都行），地址栏输入：`http://127.0.0.1:5000`
5. 粘贴 YouTube 链接 → 点「提取文案」→ 出结果后点「下载完整 txt 文件」。
   - 下载的文件也会自动存一份在 `wenan/outputs` 文件夹里。

## 三、关掉工具

回到终端窗口，按键盘 `Control + C`。

## 四、常见报错怎么办

- **网页打不开 / 转圈**：确认终端窗口还开着、程序还在跑（没按过 Control+C）。
- **提示「没有找到字幕」**：说明这个视频确实没字幕。这正是**第二步**要做的事
  （下载音频用语音识别转文字），我们做完第一步确认没问题后再加。
- **抓取失败、提示网络相关**：换个网络再试；YouTube 偶尔会限制，多试一次。
- 任何看不懂的报错，把终端里红色那几行复制给我，我用中文解释。
