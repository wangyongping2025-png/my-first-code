# YouTube 文案提取 + 智能整理小工具 · 使用说明

这个工具会：抓字幕 → 用 Claude 智能整理 → 输出 3 个文件（原始 txt、整理 Markdown、处理记录），并告诉你字数和保留比例。

> 说明：抓字幕免费；「智能整理」用的是 Claude（云端，按量极少量收费）。

## 一、第一次使用：装好需要的东西（只做一次）

1. 打开 Mac 的「终端」（启动台里搜 `终端` 或 `Terminal`）。
2. 进入工具文件夹（路径换成你电脑上 wenan 的实际位置；偷懒办法：打 `cd ` 加空格后把 wenan 文件夹拖进终端）：

   ```
   cd ~/my-first-code/wenan
   ```

3. 安装需要的工具：

   ```
   pip3 install -r requirements.txt
   ```

   最后没有红色 `error` 就算成功。若提示 `pip3: command not found`，把 `pip3` 换成 `python3 -m pip`。

## 二、填入 Claude 的 API key（只做一次）

1. 浏览器打开 **console.anthropic.com**，注册/登录。
2. 进 **Billing（账单）** 充一点点钱（建议 5 美元，能用很久；一篇通常几分到一两毛人民币）。
3. 进 **API Keys** → **Create Key**，复制那串 `sk-ant-...` 开头的密钥。
4. 在 `wenan` 文件夹里**新建一个纯文本文件，命名为 `apikey.txt`**，把那串密钥粘进去，保存。
   - 用「文本编辑」新建时，先点菜单「格式 → 制作纯文本」，再保存为 `apikey.txt`。
   - 这个文件只存在你电脑本地，**不会上传到 GitHub**（已设置好保护）。

## 三、每次使用：启动工具

1. 终端进入文件夹（同上 `cd ...`）。
2. 运行：

   ```
   python3 app.py
   ```

3. 浏览器打开 **http://127.0.0.1:5000**
4. 粘贴 YouTube 链接 → 点「提取文案」→ 稍等十几秒到一分钟 → 下载三个文件。
   - 文件也会自动存一份在 `wenan/outputs` 文件夹里。

## 四、关掉工具

回终端窗口，按 `Control + C`。

## 五、常见报错怎么办

- **提示「没有找到 Claude 的 API key」**：说明 `apikey.txt` 没建好或是空的。按第二步重做。
- **提示「API key 无效」**：密钥粘错了或多了空格，重新复制粘贴。
- **提示「没有权限/还没充值」**：去 console.anthropic.com 的 Billing 充值。
- **提示「没有找到字幕」**：这个视频确实没字幕。这是**第二步**要做的事（下载音频转文字），我们做完这步确认无误后再加。
- 任何看不懂的红色报错，复制发我，我用中文解释。
